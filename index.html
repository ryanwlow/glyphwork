Glyphwork

Rewrite the grid until it reads like the goal.

Rules pick one, then click where its top-left cell goes

    For agents

    Everything in Glyphwork is text. You can play entirely through the console above: type help, then moves like A@0,2. Several commands can go in one line, separated by ;.

    From JavaScript, window.glyphwork exposes the same game:

    glyphwork.look()          // the current level as text
glyphwork.do("A@0,2; B@1,1")  // run commands, returns the reply text
glyphwork.state()         // { level, grid, goal, rules, moves, par, solved }

    Open a level directly with ?level=N or ?level=id. Pars are exact; a solver checked every level. Progress is kept in this browser only.

    No browser? play.md explains how to play from the command line with node play.mjs.
